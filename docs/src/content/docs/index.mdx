<CardGrid>
  <Card title="Reproducible" icon="seti:lock">
    QGIS, plugins and their Python dependencies resolve together and are locked
    in `pixi.lock`. A colleague, a server or CI gets the same setup.
  </Card>
  <Card title="Dependencies included" icon="puzzle">
    Plugin metadata has no field for Python dependencies. QGIS Stack adds them
    from conda-forge, so DataPlotly brings plotly and pandas with it.
  </Card>
  <Card title="Tested" icon="approve-check">
    Each package is installed into a real QGIS and imported, on the oldest and
    newest QGIS lines it claims to support.
  </Card>
  <Card title="Straight from upstream" icon="external">
    Packages are generated from plugins.qgis.org, the versions and the QGIS
    range the plugin declares. No forks, no code changes.
  </Card>
</CardGrid>
